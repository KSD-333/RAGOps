# Evaluation Reports Directory

This directory stores evaluation run outputs generated by the evaluation engine and CLI:

```bash
ragops evaluate --dataset evaluation/datasets/golden.jsonl --version candidate-v2 --output evaluation/reports/eval_v2.json
```

Reports contain structured JSON records of:
- Aggregate retrieval metrics (Recall@5, Precision@5, MRR)
- Aggregate generation metrics (Faithfulness, Answer Relevance, Citation Accuracy)
- Latency percentiles (P50, P95, P99)
- Token and estimated cost metrics
- Per-sample evaluation breakdown
